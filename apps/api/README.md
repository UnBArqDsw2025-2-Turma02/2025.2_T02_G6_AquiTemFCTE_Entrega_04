# API - AquiTemFCTE

Backend Django REST API para o marketplace da comunidade FCTE.

## Tecnologias

- **Django 5.2.8**
- **Django REST Framework**
- **PostgreSQL**
- **Django CORS Headers**

## Scripts

- `npm run dev` - Servidor de desenvolvimento
- `npm run migrate` - Executar migrações
- `npm run makemigrations` - Criar migrações
- `npm run install` - Instalar dependências Python
- `npm run test` - Executar testes

## Estrutura

- `aquitemfcte/` - Configurações Django
- `products/` - App de produtos
- `users/` - App de usuários
- `chat/` - App de mensagens
- `manage.py` - Utilitário Django
