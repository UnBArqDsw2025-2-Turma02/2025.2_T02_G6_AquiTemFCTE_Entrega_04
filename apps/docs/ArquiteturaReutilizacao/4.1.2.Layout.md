# 4.1.2. PublicLayout

## 1. Introdução

O componente **PublicLayout** é responsável por estruturar todas as páginas públicas da aplicação, fornecendo um layout padrão que inclui cabeçalho, rodapé, espaçamento superior para compensar o header fixo e um container centralizado e responsivo. Ele garante consistência visual, facilita manutenção e elimina duplicação de estrutura entre as páginas públicas.

O layout utiliza **React**, componentes funcionais e **styled-components** para estilização, seguindo a abordagem modular adotada no projeto AquiTemFCTE.

## 2. Propósito

O componente **PublicLayout** tem como objetivos principais: 

- **Padronizar a estrutura das páginas públicas** 
- **Garantir consistência visual e responsividade** 
- **Centralizar o conteúdo dentro de um limite máximo de largura** 
- **Fornecer Header fixo e Footer constante em todas as páginas públicas** 
- **Evitar duplicação de estrutura entre rotas públicas**

## 3. Estrutura do Componente

O componente é composto por: 
- `Header`: cabeçalho fixo exibido em todas as páginas 
- `EspacamentoTopo`: div que compensa a altura do header fixo (106px) 
- `Centralização`: container externo que centraliza o conteúdo 
- `Layout`: container interno com largura máxima responsiva 
- `Footer`: rodapé exibido em todas as páginas 
- `children`: conteúdo específico de cada página pública

## 4. Código do Componente

### 4.1. index.jsx

    import { Centralização, Layout, EspacamentoTopo } from "./style";
    import Header from "../../Header";
    import Footer from "../../Footer";
    
    const PublicLayout = ({ children }) => {
      return (
        <>
          <Header />
          <EspacamentoTopo />
          <Centralização>
            <Layout>
              <main>{children}</main>
            </Layout>
          </Centralização>
          <Footer />
        </>
      );
    };
    
    export default PublicLayout;

### 4.2. style.js

    import styled from "styled-components";
    
    export const Centralização = styled.div`
      display: flex;
      justify-content: center;
    
      @media (max-width: 800px) {
        justify-content: left;
        padding-inline: 20px;
      }
    `;
    
    export const Layout = styled.div`
      display: flex;
      flex-direction: column;
      justify-content: center;
      width: 1900px;
    
      @media (max-width: 2000px) {
        width: 90%;
      }
    
      @media (max-width: 800px) {
        width: 100%;
      }
    `;
    
    export const EspacamentoTopo = styled.div`
      height: 106px;
    `;

## 5. Props

| Prop       | Tipo      | Obrigatório      | Descrição  |
| ---------- | --------- | ---------------- | ---------- |  
| `children` | ReactNode | Sim              | Conteúdo da página que será renderizado dentro do layout |

## 6. Funcionamento e Responsividade

* O **Header é fixo**, então o `EspacamentoTopo` evita sobreposição do conteúdo.
* O container `Centralização` centraliza o conteúdo em telas grandes e aplica padding lateral em telas menores.
* O `Layout` limita a largura máxima a **1900px**, reduzindo para **90%** em telas médias e **100%** em telas pequenas.
* O Footer permanece sempre ao final da página.

## 7. Exemplo de Uso

    import PublicLayout from "../../../components/(layout)/PublicLayout";
    
    <PublicLayout>
      <Routes>
        <Route path="/login" element={<LoginPage />} />
        <Route path="/signup" element={<SignUpPage />} />
      </Routes>
    </PublicLayout>

## 8. Onde é Utilizado

* Rotas públicas da aplicação\`apps/web/src/routes/PublicRoutes.jsx`
* Todas as páginas que não exigem autenticação. Como: 
    - Login
    - Signup 
    - Recuperação de senha

## 9. Visão Crítica

### Pontos Fortes

* Estrutura simples e clara
* Facilita padronização visual
* Completamente responsivo
* Reaproveitável em qualquer rota pública

### Pontos de Melhoria

* Poderia suportar tema dinâmico (dark/light)
* Poderia incluir opção de ocultar Header ou Footer
* TypeScript ou PropTypes aumentariam a segurança de tipos

## 10. Conclusão

O componente PublicLayout é essencial para manter a organização e a padronização das páginas públicas do AquiTemFCTE. Sua estrutura simples, aliada ao uso de styled-components, ajuda a garantir uma experiência visual consistente e responsiva. Ao concentrar a lógica de layout em um único lugar, o projeto evita código duplicado e facilita bastante a manutenção. Embora ainda existam possibilidades de evolução, a implementação atual já atende muito bem às necessidades da aplicação.
